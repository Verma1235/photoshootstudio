📸 #PhotoShootStudio

1. Initial Setup

# Clone the project

```bash
git clone https://github.com/Verma1235/photoshootstudio.git
cd PhotoShootStudio
```

2. \*\*Run Backend (run one-by-one)

```bash
cd backend
npm install
npm start
```

3. \*\*Run Frontend
   Open a new terminal in VS Code:

```bash
cd frontend
npm install
npm run dev
```

🛠 \*\*Working with Branches (Contribution)
If you want to add something new (like a gallery or login):

Create a branch:

```bash
 git switch -c branch-name
```

Save your work:

```bash
git add . then git commit -m "done"
```

Upload to GitHub:
```bash
 git push -u origin branch-name
 ```
